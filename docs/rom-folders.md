# ROM folder names

`tools/make_playlists.py` expects the folder names of the stock EmuELEC card. Put each system's games in its folder at the root of the ROMS partition, and BIOS files in `bios/`. Subfolders are fine. Files with other extensions (save files, screenshots, `gamelist.xml`) are ignored.
